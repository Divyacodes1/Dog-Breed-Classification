# Dog-Breed-Classification
Dog Vision — Dog Breed Classification  An end-to-end deep learning project that identifies the breed of a dog from an image using image classification and transfer learning.  The project uses TensorFlow, TensorFlow Hub, and MobileNetV2 to classify dog images into 120 different dog breeds.

Dog Vision is a computer vision project designed to solve this problem. Given an image of a dog, the trained model predicts the most likely dog breed.

The project follows an end-to-end machine learning workflow:

Image → Preprocessing → Tensor → Deep Learning Model → Prediction → Dog Breed

The model is built using transfer learning with the MobileNetV2 architecture available through TensorFlow Hub.
